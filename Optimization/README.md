# Optimization Projects

This repository contains a collection of **optimization-focused projects** across multiple domains, demonstrating the application of **mathematical modeling**, **operations research**, **machine learning**, and **data science** techniques.
Each project is implemented in Python (primarily using Jupyter Notebooks) and tackles real-world optimization challenges.

## 📂 Project Structure

| File / Folder                                                                                            | Description                                                                                                        |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Optimization airlines/**                                                                               | Optimization tasks related to airline scheduling and resource allocation.                                          |
| **Comprehensive Case Study Optimization of a Continuous Stirred-Tank Reactor (CSTR) Using Gurobi.ipynb** | A chemical engineering optimization case study using **Gurobi** for process efficiency in CSTR systems.            |
| **Fantasy Football Team Selection Optimization.ipynb**                                                   | Model for selecting an optimal fantasy football team based on performance metrics and constraints.                 |
| **Furniture Production Optimization – WoodCraft Wonders.ipynb**                                          | Optimization of production schedules to maximize output while minimizing costs in furniture manufacturing.         |
| **Optimization of a Second Order Reaction Using Gurobi.ipynb**                                           | Reaction rate optimization for a second-order chemical process using **linear and nonlinear programming**.         |
| **Optimization\_Production\_distribution\_optimization.ipynb**                                           | Production and distribution network optimization to reduce costs and improve supply chain efficiency.              |
| **Optimization\_Utilizing Renewables and Energy Storage to Minimize Electricity Use.ipynb**              | Optimal energy management strategy leveraging **renewable energy sources** and **energy storage systems**.         |
| **Optimizing Deep Neural Network (DNN) for Embedded System.ipynb**                                       | Hyperparameter tuning and model size optimization for deploying **DNNs** on resource-constrained embedded devices. |
| **Optimizing Solar Energy Use with Forecasting & Gurobi.ipynb**                                          | Solar energy production and usage optimization using demand forecasting and Gurobi solver.                         |
| **Production planning optimization problem for a single facility over 5 months.ipynb**                   | Linear programming model for long-term production planning at a single manufacturing facility.                     |

## 🛠 Technologies & Tools Used

* **Python** (NumPy, Pandas, Matplotlib, Seaborn)
* **Optimization Solvers**: [Gurobi](https://www.gurobi.com/), SciPy Optimize
* **Machine Learning**: scikit-learn, TensorFlow/Keras (for DNN optimization)
* **Data Visualization**: Matplotlib, Plotly
* **Jupyter Notebook** for analysis & presentation

## 📈 Key Skills Demonstrated

* **Linear & Integer Programming**
* **Mixed-Integer Linear Programming (MILP)**
* **Nonlinear Optimization**
* **Energy Management Systems**
* **Process Optimization in Manufacturing & Chemical Engineering**
* **Forecasting & Predictive Modeling**
* **Resource Allocation & Scheduling**
* **Model Deployment for Embedded Systems**
